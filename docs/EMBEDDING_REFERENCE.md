# Embedding reference vectors (retired)

`fixtures/embedding_reference.json` was a cross-repository contract file (plan
Task 0.6, ruling R9): 200 fixed strings, each embedded by the Rust
implementation's fastembed 3.14.1 `all-MiniLM-L6-v2`, with full-precision
vectors. The Go embedder was held to the CLS projection of its raw model
output at cosine ≥ 0.9999. That pinned the model file, the tokenizer and the
attention mask, and left only the pooling choice outside it (plan §II.10
row 16).

It was retired by `openspec/changes/passage-vectors`, when Go stopped running
all-MiniLM-L6-v2. There is no longer a model the two implementations share, so
there is no vector to compare across them. A Rust snapshot's vectors are
recomputed on import, and `docs/PARITY.md` records the divergence.

What replaced it is `fixtures/pplx_embedding_reference.json`, described in
`docs/FIXTURES.md`. It is generated by an independent Python implementation of
the new model's published pipeline, and Go is held to it per document and per
passage.

The file and its generator's history are in git: the fixture was deleted in the
commit that retired it, and the generator lives in the frozen Rust repository at
`crates/remem-server/src/bin/embedding_reference/`.
